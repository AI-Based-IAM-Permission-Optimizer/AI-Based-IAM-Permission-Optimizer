# IAM Guard Admin Dashboard

Static HTML/CSS/JavaScript frontend for the IAM Guard security-review workflow.

## Structure

- `index.html` — application shell and views
- `css/style.css` — responsive UI and themes
- `js/app.js` — UI logic, API integration, review workflow
- `js/config.js` — API endpoint configuration

Open `http://127.0.0.1:5500/`.

Admin demo login is handled by the frontend for the presentation environment.
default pass=admin123

## Backend

The API base URL is configured only in `js/config.js`. No frontend fallback/demo dataset is enabled.
